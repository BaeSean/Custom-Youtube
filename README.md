# Custom Youtube (CustomYT)

유튜브 일반 영상과 Shorts 화면의 원본 패널을 드래그하고 크기를 조절하는 Chrome 확장 프로그램입니다. 현재 버전은 **0.11.6**입니다.

## 지원 기능

- 일반 영상: 영상, 기본정보, 설명, 댓글, 추천 영상, 추천 Shorts 배치 편집
- 기본 모드와 영화관 모드 동기화 및 모드별 배치 저장
- 기본 모드의 설명 있음·없음 배치 분리
- Shorts: 영상, 기본정보, 액션 버튼, 댓글 편집 및 댓글 열림·닫힘 배치 분리
- 이름 있는 프리셋 저장·불러오기·덮어쓰기·삭제
- 우하단 모서리 크기 조절, 겹치는 패널 밀어내기, 가장자리 스냅
- Alt를 누르면 자유 이동, 방향키 조절, 되돌리기 및 원래 배치 복원
- 화면 상단 편집 버튼과 화면 유형별 설정 탭

## 설치 및 업데이트

1. 이 저장소를 내려받아 압축을 해제합니다.
2. Chrome의 `chrome://extensions`에서 개발자 모드를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누르고 `manifest.json`이 있는 폴더를 선택합니다.
4. 업데이트할 때는 확장의 새로고침 버튼을 누른 뒤 YouTube 탭도 새로고침합니다.

별도 빌드나 의존성 설치는 필요하지 않습니다. 화면 상단 편집 버튼을 누르고 패널 이름을 드래그하거나 우하단 모서리로 크기를 조절합니다. 완료하면 마지막 적용 배치가 유지됩니다. 이름 있는 프리셋은 설정에서 별도로 저장합니다.

## 검증

Node.js가 설치된 환경에서 실행합니다.

```sh
npm run check
npm test
npm run dev
```

로컬 재현 화면: `http://127.0.0.1:4173/watch`, `http://127.0.0.1:4173/shorts/fixture-1`.

자동 테스트는 좌표 계산·겹침 방지·스냅·저장 데이터 등을 검증합니다. 실제 YouTube DOM 전체 동작을 보장하지는 않습니다. 실제 Chrome에서 Shorts 댓글 재열기, 다음 영상 전환 시 좌표 유지, 영상 이동·크기 변경에 따른 재생바 및 상단 버튼 정렬을 확인했습니다. 모든 전환 프레임을 녹화 검증한 것은 아닙니다.

## 범위와 제한

- 홈·검색·구독·기록·재생목록 목록 화면 편집은 아직 구현하지 않았습니다.
- YouTube의 화면 구조 및 계정별 실험 변경에 따라 추가 대응이 필요할 수 있습니다.
- 창이 너무 좁거나 지원하지 않는 표시 상태에서는 원래 배치로 복귀할 수 있습니다.
- 사용자 설정은 `chrome.storage.local`에 보관하며 저장소에는 포함하지 않습니다.
- 외부 분석 SDK와 서버 전송 기능은 사용하지 않습니다. 확장 권한은 `storage`이며 콘텐츠 스크립트는 YouTube에서만 실행합니다.

## 파일 구성

| 파일 | 역할 |
| --- | --- |
| `layout.js` | 배치·충돌·스냅 좌표 계산 |
| `content.js`, `content.css` | 일반 영상 편집·모드·프리셋 |
| `shorts.js`, `shorts.css` | Shorts 편집·댓글 상태별 배치·컨트롤 정렬 |
| `tests/` | 자동 테스트와 로컬 재현 화면 |
| `tools/dev-server.cjs` | 로컬 검증 서버 |

진행 요약은 [진행 현황](docs/PROGRESS.md), 과거 단계별 기록은 [개발 이력](docs/DEVELOPMENT_HISTORY.md)을 참고하세요. 개발 이력에는 당시의 미검증 사항과 이후 변경된 과거 동작도 포함되어 있습니다.
