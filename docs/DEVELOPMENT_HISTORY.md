# CustomYT 0.11.6

PC Chrome의 유튜브 영상 화면(`/watch`)과 Shorts 화면(`/shorts/`)에서 원본 콘텐츠를 보면서 배치를 편집합니다.

## 설치·업데이트

1. `chrome://extensions`를 엽니다.
2. 처음 설치할 때는 개발자 모드 → 압축해제된 확장 프로그램 로드 → `F:\Programming\customYT`를 선택합니다.
3. 이미 설치했다면 CustomYT 카드의 새로고침 버튼을 누르고 버전 **0.11.6**을 확인합니다.
4. 유튜브 탭도 새로고침합니다.

빌드나 라이브러리 설치는 필요 없습니다. 0.3.0의 설정은 유지합니다. 예전 댓글 내용만 기준으로 저장된 배치의 크기가 어색하면 해당 모드에서 배치를 초기화해 다시 편집하세요.

## 사용 방법

### 0.11.6 실제 Chrome 잔상 원인 대응

- 사용자 Chrome에서 원래 위치에 남아 있는 `.reel-video-in-sequence-thumbnail`의 `frame0.jpg` 이미지를 확인했습니다. 커스텀 배치에서는 이 별도 미리보기를 숨깁니다.
- 새 플레이어가 붙을 때 스크립트가 찾아내기 전에도 저장 좌표를 상위 Shorts의 CSS 변수로 즉시 상속합니다.
- 댓글 열림 애니메이션의 화면 밖 좌표 때문에 저장 배치를 놓치지 않도록, 댓글의 명시적 열림 상태로 패널을 찾습니다.
- 실제 Chrome에서 댓글 닫기·다시 열기 후 너비 463.99px 유지, 다음 영상 URL 전환 직후와 완료 후 영상 X=877.55px 및 댓글 너비 유지를 확인했습니다. 전환의 모든 프레임을 녹화해 검증한 것은 아닙니다.
- 문법 검사와 기존 테스트 31개 통과. 검증 화면: `artifacts/shorts-live-0.11.6.png`.

### 0.11.5 Shorts 플레이어 로딩·교체 대응

- 실제 YouTube DOM에서 로딩 중 video의 top이 -624px인 상태를 관찰했습니다. 현재 영상 판별은 video 대신 플레이어 영역을 사용하며, 여러 후보가 있으면 현재 URL에 연결된 플레이어를 우선합니다.
- 새 플레이어 DOM 적용을 다음 프레임까지 미루지 않고 mutation 이후 microtask에서 처리합니다. 커스텀 영상 배치에서는 별도의 Shorts 시네마틱 배경을 숨기고 내부 video의 transform·transition을 해제합니다.
- 로컬 `/shorts/fixture-1?transition=1`에서 video 화면 밖 이동과 애니메이션 프레임 내 플레이어 교체를 재현했습니다. 교체 후 다음 프레임에 배치 적용, video와 플레이어 좌표 일치, 댓글 닫기 후 닫힘 배치 복원을 확인했습니다. 실제 사용자 화면의 잔상 제거 여부는 미검증입니다.

### 0.11.4 Shorts 배경 및 전환

- 액션 패널 배경을 투명하게 변경합니다. 배치 적용 중 원래 댓글 컨테이너의 배경·테두리·그림자와 영상 컨테이너 배경을 제거하고, 위치 전환 애니메이션을 해제합니다. 초기화·화면 이탈 시 복원합니다.
- Shorts 사이 이동 시작 시 배치를 미리 해제하지 않습니다. DOM 교체와 배치 전환을 다음 프레임에 처리하며, 커스텀 배치 사이 전환에서는 불필요한 플레이어 resize 이벤트를 보내지 않습니다.
- 로컬 검증: 다음 영상 전환 시작 직후 댓글의 배치 클래스 유지, 댓글 너비 304px 유지, 액션 배경 투명, 일반 영상 이탈 시 추가 클래스 0개. 문법 검사와 기존 31개 테스트 통과. 사용자 화면의 잔상 및 원래 댓글 테두리는 직접 재현하지 못했으므로 실제 YouTube 확인이 필요합니다.

### 0.11.3 Shorts 댓글 상태별 배치

- 댓글 있음·없음 배치를 독립적으로 편집하고 자동 전환합니다. 프리셋 저장·덮어쓰기·불러오기는 두 상태를 하나의 이름으로 함께 처리합니다. 설정에 현재 편집 상태를 표시합니다.
- 기존 배치·프리셋은 댓글 슬롯 포함 여부에 해당하는 상태로 보존합니다. 반대 상태는 원래 유튜브 배치로 시작합니다. 원래 배치 복원과 되돌리기는 현재 상태에만 적용합니다.
- 로컬에서 닫힘 상태 영상 x=488.5px 유지, 댓글 너비 320→304px 변경 후 닫기·재열기, 프리셋 저장·복원, 새로고침 후 닫힘 배치 복원을 확인했습니다. 실제 YouTube 확장 적용 검증은 미실행입니다.

### 0.11.2 이전 배치 자동 적용 수정

- 이전 저장 형식의 현재 배치는 백업 프리셋으로 보관하고 한 번 원래 유튜브 배치로 시작합니다. 기존 이름 있는 프리셋은 유지됩니다.
- 화면 밖 이전 플레이어 대신 화면 안에 실제 영상이 보이는 플레이어를 선택합니다. 영상의 상위 컨테이너 대신 실제 플레이어에 배치를 적용합니다.
- `/shorts/fixture-1?legacy=1`에서 이전 좌측 배치와 화면 밖 플레이어를 함께 재현해 기본 위치 유지 및 현재 플레이어 선택을 확인했습니다. 문법 검사·31개 테스트 통과. 실제 사용자 YouTube 화면 검증은 미실행입니다.

### 0.11.1 Shorts 기본 배치 유지

- 최초 편집 진입은 원래 유튜브 위치와 크기를 유지하고 테두리만 표시합니다. 실제 조작을 시작할 때 현재 좌표를 읽습니다. 원래 영상 위에 겹친 정보는 실제 조작 시 겹침 방지 규칙으로 분리됩니다.
- 되돌리기는 일반 영상처럼 상단 편집 버튼 옆에 표시합니다. 첫 조작을 되돌리면 원래 유튜브 배치로 복원합니다.
- 기존 저장 배치는 유지합니다. 이전 버전의 왼쪽 배치를 없애려면 설정 → Shorts → Shorts 원래 배치로 복원을 한 번 누르세요.
- 로컬 브라우저에서 편집 전후 영상 좌표·크기 일치와 이동 후 되돌리기 복원을 확인했습니다. 실제 YouTube 확장 적용 검증은 미실행입니다.
### 0.11.0 Shorts 재생 화면 편집

- Shorts 화면 상단의 **Shorts 편집** 또는 설정 → **Shorts** 탭에서 시작합니다. 처음 편집하면 영상·기본정보·액션 버튼·댓글의 독립 배치를 만듭니다. 댓글은 원래 댓글 버튼으로 열었을 때만 표시하며, 닫아도 저장한 자리는 유지합니다.
- 제목 손잡이로 이동하고 우하단 모서리로 크기를 조절합니다. 겹치는 패널 밀어내기, 10px 스냅, 8px 간격, Alt 자유 조절, 방향키 조절, Esc 취소를 지원합니다.
- Shorts 배치와 이름 있는 프리셋은 일반 영상과 별도로 저장합니다. 다음 Shorts와 새로고침에는 마지막으로 적용한 배치를 사용합니다. 프리셋 불러오기·덮어쓰기·삭제, 되돌리기, 원래 배치 복원도 Shorts 탭에서 제공합니다.
- 원본 콘텐츠를 이동하거나 복제하지 않고 표시 위치를 조절합니다. 다음 영상으로 넘어가는 원래 피드와 댓글 스크롤을 유지합니다. 창 너비 760px 미만이거나 플레이어를 찾지 못하면 원래 화면을 사용합니다.
- 검증: 문법 검사 및 자동 테스트 30개 통과. 로컬 브라우저에서 이동 스냅·크기 조절, 저장·새로고침 복원, 프리셋 저장·불러오기, 댓글 닫기·재열기, 영상 위 휠 전환, 댓글 독립 스크롤, 일반 화면 이탈 시 스타일 해제를 확인했습니다. 실제 YouTube DOM을 참고했지만 실제 YouTube에 확장을 적용한 통합 검증은 미실행입니다.

### 0.10.0 패널 스냅

- 마우스로 이동·모서리 크기 조절 시 화면 경계 및 다른 패널 끝선의 10 CSS px 이내에서 자동 정렬합니다. 나란한 패널 사이에는 8px 간격을 둡니다. 정렬 시 녹색 안내선을 표시합니다.
- Alt를 누른 상태로 드래그하면 스냅을 해제합니다. 키보드 방향키는 기존 간격으로 조절합니다. 저장 방식·겹침 방지·밀어내기는 유지됩니다.
- 자동 테스트에 경계 정렬, 패널 간격, 크기 조절, 거리 밖 이동, 스냅 비활성화를 추가했습니다. 실제 사용자 브라우저 드래그 검증은 미실행입니다.

### 0.9.5 영화관 제목 한 번 클릭

- 영화관에서 제목 클릭 시 기본모드와 설명 표시를 명시적으로 함께 요청합니다. 로드된 설명은 네이티브 토글 상태와 무관하게 엽니다. 콘텐츠가 아직 없으면 원래 클릭 이벤트를 허용해 유튜브가 로드하도록 합니다.
- 로컬에서 설명 닫기→영화관→제목 한 번 클릭 후 기본모드·설명 있음 상태를 확인했습니다. 문법 검사 및 테스트 28개 통과. 실제 사용자 YouTube 검증은 미실행입니다.

### 0.9.4 자동 복원 중 기존 패널 위치 보호

- 댓글 위치 자동 복원 시 Shorts 등 기존 패널을 밀던 처리를 제거했습니다. 다른 패널과 겹치면 댓글은 새로 확보한 빈 위치에 남습니다. 이미 저장된 위치는 임의로 복구하지 않습니다.
- 설정의 영상 재생→패널 상태 확인→현재 상태 확인에서 Shorts 탐색 여부, 저장 좌표, 실제 크기·위치, 화면 아래 여부, 숨김 상위 요소를 확인할 수 있습니다. URL·영상 제목·댓글 내용은 포함하지 않습니다.
- 문법 검사와 테스트 28개 통과. 댓글 복원 충돌 시 기존 Shorts 좌표가 유지되는 회귀 테스트를 추가했습니다. 사용자 화면의 Shorts 소실은 직접 재현하지 못했으며 실제 진단 결과가 필요합니다.

### 0.9.3 설명 표시 상태 기억

- 기본모드 설명 열림·닫힘 선택을 배치와 별도로 저장하고 모드 왕복 시 복원합니다. 새 기본모드 프리셋 저장·덮어쓰기에는 표시 상태도 포함합니다.
- 커스텀 배치의 제목 클릭은 로드된 설명을 명시적으로 열고, 닫기는 표시 상태만 변경합니다. 네이티브 visibility 속성만 바꿔 유튜브 내부 토글 상태와 어긋나던 처리를 제거했습니다.
- 로컬에서 제목 클릭 열기→닫기→영화관→기본 복귀 후 닫힘 유지→제목 재열기를 확인했습니다. 실제 사용자 YouTube 검증은 미실행입니다.

### 0.9.2 설명을 통한 기본모드 진입

- 영화관에서 설명이 열리면 기본모드 설정과 설명 있음 배치를 적용합니다. 로드된 댓글은 다른 기본모드 배치의 댓글 위치도 참고해 복원합니다.
- 기본모드 설명 패널의 닫기 버튼은 네이티브 모드 복귀 핸들러 대신 설명만 숨깁니다. 인식되지 않는 닫기 경로는 기존 모드 복구 처리를 유지합니다.
- 로컬에서 댓글 로드→영화관→설명 열기로 기본모드 복귀 시 댓글·설명 모두 표시됨을 확인했습니다. 설명 닫기 후 기본모드·댓글 유지, 네이티브 닫기 핸들러 미실행을 확인했습니다. 실제 사용자 YouTube 검증은 미실행입니다.

### 0.9.1 설명 닫힘 시 기본모드 유지

- 기본모드에서 설명 패널이 닫히는 것은 설명 없는 배치로의 전환으로 처리합니다. 네이티브 패널 닫힘이 플레이어 모드를 바꾸면 기본모드를 다시 적용합니다. 직접 누른 모드 버튼·설정 변경은 이 처리에서 제외합니다.
- 로컬 /watch?variant=refresh&exclusive-panels=1&close-description-theater=1 에서 설명 닫힘과 영화관 전환을 함께 발생시킨 뒤 기본모드·설명 없음으로 복구됨을 확인했습니다. 실제 사용자 YouTube 검증은 미실행입니다.

### 0.9.0 기본모드의 설명별 배치와 영화관 패널

- 기본모드에서는 설명 있음/없음 배치를 각각 편집하고 자동 전환합니다. 설정에 현재 상태를 표시합니다. 기본모드 프리셋 저장·덮어쓰기는 두 배치를 하나의 프리셋 안에 저장합니다.
- 기존 기본모드 배치는 설명 있음 상태로 유지하고, 설명 없음 상태는 설명 슬롯을 제외한 복사본으로 시작합니다. 기존 프리셋도 불러올 때 같은 방식으로 변환합니다. 처음에는 남은 공간이 유지되므로 각 상태에서 원하는 크기와 위치로 편집하세요.
- 영화관모드는 댓글과 설명을 모두 숨기고 배치 대상에서도 제외합니다. 다른 패널의 위치를 자동으로 늘리지는 않습니다.
- 로컬에서 설명 없음 영상 너비 727.55px / 설명 있음 743.55px 독립 저장·복원 및 단일 프리셋 불러오기를 확인했습니다. 영화관 표시 대상은 영상·기본정보·추천영상·Shorts이며 댓글·설명 display:none을 확인했습니다. 실제 사용자 YouTube 검증은 미실행입니다.

### 0.8.3 설명 숨김과 Shorts 후보 선택

### 0.6.4 아이콘 판별 반전 수정

0.6.3의 SVG 아이콘 판별이 반대로 작성되어 반대 모드의 저장 배치를 적용했습니다. 사용자 제공 두 이미지의 화살표 방향과 대조해 수정했습니다. 안쪽 화살표(기본보기로 축소)는 현재 영화관, 바깥쪽 화살표(영화관으로 확대)는 현재 기본입니다. 재현 화면의 아이콘 데이터도 함께 바로잡았습니다. 0.6.3의 로컬 검증은 같은 잘못된 매핑을 사용했으므로 실제 모드 정확성의 근거로 삼을 수 없습니다.

### 0.6.3 호버 지연·영상 이동·Shorts 재등장

- 실제 유튜브 DOM에서 모드 버튼의 aria-label과 tooltip 속성이 서로 모순되는 상태를 확인했습니다. 현재 관측된 두 SVG 화살표 형태를 우선 판별하고, 알 수 없는 아이콘은 기존 문구 판별로 돌아갑니다. 아이콘 변경을 감시하고 확인 대기를 100ms로 줄였습니다. 유튜브가 아이콘을 변경하면 추가 대응이 필요할 수 있습니다.
- 플레이어에서 사용자가 직접 모드를 바꾼 경우에만 저장 모드를 갱신합니다. 영상 진입 중 일시적인 모드가 설정을 덮어쓰지 않으며 초기 4초 동안 늦게 적용된 유튜브 모드도 저장한 선택과 맞춥니다.
- 기존 추천 영역 밖의 Shorts 및 확장이 숨긴 컨테이너 안에 새로 로드된 Shorts를 다시 찾습니다. 아직 콘텐츠가 없는 동안에도 저장된 배치 좌표는 삭제하지 않습니다.

### 0.6.2 버튼 문구 판별

버튼 설명은 전환 대상입니다. `영화관 모드`가 표시되면 현재 기본 모드, `기본보기` 또는 `기본 보기`가 표시되면 현재 영화관 모드입니다. 붙여 쓴 기본보기를 놓치던 정규식을 수정했습니다. 읽을 수 없는 상태를 기본 모드로 추정해 토글하지 않습니다. aria-label을 우선 읽고 title 및 툴팁 속성을 보조로 사용합니다.

### 레이아웃 프리셋 (0.5.0)

**⋯ → 레이아웃 프리셋**에서 이름을 입력하고 현재 배치를 저장합니다. 최대 30개, 이름은 40자까지 지원합니다. 저장한 항목을 선택해 불러오기·명시적 덮어쓰기·삭제를 할 수 있습니다. 현재 기본/영화관 모드도 함께 저장하며, 불러오면 해당 모드로 전환합니다. 불러온 배치를 편집해도 프리셋 원본은 유지됩니다. 수정하지 않은 원본 배치는 해당 모드의 원본 배치로 저장됩니다. 삭제해도 현재 적용 중인 배치는 유지됩니다.

프리셋은 `customyt.presets.v1`에 별도로 저장합니다. 새 페이지에서 목록 유지, 편집 전 너비 복원(795.55px), 다른 모드에서 영화관 프리셋 불러오기, 덮어쓰기·삭제를 로컬 브라우저로 검증했습니다. 문법 검사와 기존 자동 테스트 22개도 통과했습니다. 실제 사용자 Chrome 검증은 미실행입니다.

- 상단 오른쪽 프로필·알림·만들기 버튼 왼쪽에 편집 버튼이 표시됩니다.
- **⋯ → 화면 모드**에서 **기본 모드 / 영화관 모드**를 선택합니다. 처음에는 기본 모드입니다. 선택은 즉시 적용되고 다음 영상에서도 사용합니다. 두 모드의 사용자 배치는 따로 저장됩니다.
- **화면 편집**을 누르면 현재 영역에 테두리가 나타납니다. 누르기만 해서는 배치가 바뀌지 않습니다.
- 영역 이름을 창처럼 끌어 빈 공간으로 자유롭게 이동합니다. 크기와 나머지 영역은 유지됩니다. 겹치는 패널은 크기를 유지하며 아래로 연쇄 이동합니다.
- 오른쪽·아래쪽 테두리를 당겨 선택한 영역만 조절합니다. 다른 영역에 닿으면 해당 패널을 아래로 밀며, 축소한 공간은 여백으로 남습니다. 경계에 Tab으로 이동한 뒤 방향키로도 조절할 수 있습니다.
- **완료**를 누르면 테두리가 사라지고 변경한 배치는 유지됩니다. 각 영역의 내용은 독립적으로 스크롤할 수 있습니다.
- **되돌리기**는 최근 25회 변경을 되돌립니다. Esc는 드래그를 취소하며, 편집 중 다시 누르면 이번 편집을 취소합니다.
- **⋯ → 유튜브 기본 배치로 초기화**는 현재 모드의 사용자 배치를 해제합니다.
- **설명 열기 / 댓글 열기**는 유튜브 버튼을 통해 실제 콘텐츠를 불러옵니다. 저장한 배치에 없던 영역은 기존 영역을 움직이지 않고 아래쪽 빈 공간에 추가합니다.

## 이번 수정

추천 카드의 가로 배열을 강제로 세로 목록으로 바꾸던 CSS를 제거했습니다. 댓글·설명은 engagement 패널의 제목·입력창·바깥 틀을 포함해 편집하며 원래 display·배경·패딩·테두리를 유지합니다. 이동은 자리 교환에서 자유 이동으로 바꿨습니다. 모드 전환 중에는 기존 사용자 배치를 해제하고 실제 theater 상태 변경을 기다립니다. 6초 안에 전환이 확인되지 않으면 실패 안내를 표시합니다.

영상·기본 정보·설명·댓글·추천 영상·추천 Shorts 중 실제로 로드된 영역을 편집합니다. 원본 DOM과 영상 노드를 이동하거나 복제하지 않습니다. 유튜브에서 영상 부모 높이가 0인 경우도 영상 크기가 확보되도록 기존 수정 사항을 유지합니다.

## 제한 사항

- 홈·검색·구독·기록·Shorts 재생 화면은 편집하지 않습니다.
- 전체화면, 라이브 채팅·재생목록이 열린 화면에서는 사용자 배치를 잠시 해제합니다.
- 창 너비가 부족하면 원본 배치로 돌아가며 다시 넓히면 저장한 배치를 적용합니다.
- 이미 겹쳐 열린 네이티브 팝업 영역이 있으면 해당 영역을 닫은 뒤 편집해야 합니다.
- 최소 크기보다 작은 원본 영역은 원래 크기를 허용합니다.
- 추천 Shorts 묶음이 여러 개면 첫 번째 묶음을 분리합니다.

- 실제 유튜브에서 영화관 전환 후에도 watch의 theater 속성이 없고 버튼 aria-label만 기본 보기로 바뀌는 구조를 확인했습니다. 모드 판별에 이 상태를 반영하고 영상 ID 변경 시 재적용하며 초기 상태가 700ms 유지되는지 확인합니다.

`layout.js`는 좌표 계산, `content.js`는 인라인 편집·DOM 감지·저장, `content.css`는 패널 표시와 영상 크기를 담당합니다. 설정은 `chrome.storage.local`의 `customyt.watch.v3`에 저장합니다. 권한은 storage와 유튜브 콘텐츠 스크립트뿐이며 외부 서버·분석 SDK·라이브러리는 사용하지 않습니다. `tests/`와 `tools/`는 로컬 검증용입니다.
